# Исторический листинг премиальных опционов CNY: первый этап

Проверка запроса futures-analytics от 15.10.2026. Только `asset_code=CNY`,
`exec_type=E`, `margin_style=P`, `settle_type=S`, `underlying_asset=CNYRUB_TOM`.
Приоритеты 2–3 (денежная механика, ГО, котировки, общий счёт) не выполняются.

## Состав пакета

- `consumer_coverage.json`: неизменённые 22 сигнала потребителя.
- `raw/`: ответы ISS с включёнными истёкшими сериями и реестрами контрактов,
  текущий торговый список; `sources.json` содержит URL, время проверки и HTTP-статус.
- `series.parquet`: весь соответствующий фильтру реестр; `contracts.parquet`:
  контракты всех найденных серий с экспирацией через 28–42 календарных дня.
- `local_series.parquet`, `local_contracts.parquet`: локальные реестры до проверки.
- `history.parquet`: локальные дневные наблюдения выбранных контрактов до 14.10.2026.
  Это данные DuckLake, а не повторно скачанная история ISS.
- `listing_matrix.parquet`: сигнал × подходящая экспирация, объявленная дата
  начала серии и заключение; `coverage.parquet`: сводка по сигналам.
- `strikes.parquet`: контракты CNYP051126XE, наблюдения 01.10.2026 и два
  порога крыльев. Строка с пустым SECID означает непокрытый запрос, не контракт.
- `current_target.json`: соответствующие серии строки текущего торгового списка.
- `fresh_signal_history.parquet`: повторная загрузка дневных записей каждого
  контракта CNYP051126XE на 01.10.2026; сравнение BOARDID/NUMTRADES с локальной
  историей отражено в `strikes.parquet`. Полная история заново не скачивается.
- `gaps.parquet`: ограничения и необходимые для их закрытия источники.
- `summary.json`, `manifest.json` (SHA-256 каждого файла), `build_script.py`.

## Интерпретация и ограничения

`start_date` — объявленная ISS дата начала серии, доступная в сегодняшнем
архивном реестре. Она не является доказательством исторического времени
публикации и не задаёт дату листинга каждого страйка.

`not_yet_listed` — дополнительный статус: дата начала конкретной серии позже
сигнала, противоречащих более ранних дневных наблюдений в выбранной локальной
истории не найдено. Это не `never_listed`: серия существует позднее.
Отсутствие иных серий во всём историческом листинге не доказано.

`listed_no_trades` — есть дневная строка на сигнал с нулевым NUMTRADES;
`listed_with_trades` — дополнительный статус для положительного NUMTRADES.
Оба статуса относятся к наблюдению за день, не доказывают доступность на
открытии сессии, наличие котировок и исполнение четырёх ног одновременно.
Неизвестные значения NUMTRADES не превращаются в нули.

`unknown` — отсутствие подтверждения, включая ненайденные дальние страйки.
Отсутствие записи в реестре или истории не объявляется `never_listed` либо
`history_missing`. Последний требует независимого подтверждения листинга.

`listed_at`, `delisted_at`, `known_at` оставлены пустыми, когда нет доказательств.
`history_from`, `history_till`, первое наблюдение и экспирация не подменяют эти
поля. Короткий код связывается с серией только в интервале истории реестра;
пересекающиеся назначения одного кода приводят к ошибке сборки.
Контракты без истории сохраняются в реестре. Нули объёма не удаляются.

Свежий реестр получен после исторического среза: его нельзя напрямую использовать
как universe, известный в прошлом. Ни одна строка не получает фиктивный known_at.
Для окончательного ответа по отсутствующим крыльям нужен архив назначенных
в торги инструментов/журнал добавления страйков на 01.10.2026 от MOEX.

[Сообщение MOEX о запуске](https://www.moex.com/n56990) сохранено только как
контекст 2023 года. Описанный там порядок добавления серий нельзя автоматически
распространить на 2025–2026 или использовать вместо действовавших спецификаций.

## Воспроизведение

```powershell
$env:MOEX_DATA_ROOT = 'F:/moex-data'
python -m scripts.check_options_listing --output F:/moex-data/reports/options-listing-NEW
```

Нужны доступ к ISS и чтение DuckLake. Каталог результата обязан быть новым.
Основные таблицы DuckLake, прежние пакеты и проект потребителя не изменяются.
При сетевой ошибке незавершённый каталог сохраняется без итогового manifest;
его нельзя принимать как готовый пакет.
