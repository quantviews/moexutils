## Воспроизводимый отчет

```powershell
$env:MOEX_PG_USER = 'moex_reader'
python -m moexutils.futures_audit
```

Запись выполняется только в `<MOEX_DATA_ROOT>/reports/futures-audit/<UTC-время>.json`.
Хранилище читается в одной транзакции. JSON содержит `snapshot_id`, время создания,
версию схемы и SHA-256 кода отчета. Старые отчеты сохраняются. `--output` задает
другую папку. В ночном шаге 1e отчет строится после обновления параметров;
ошибка формирования попадает в общий список предупреждений. Обнаруженные
исторические аномалии остаются в отчете и не вызывают исправление цен.

Основные разделы JSON:

- `instruments` — история по точному SECID, наличие в реестре, исходные типы,
  активы из реестра/карточки отдельно, признаки их конфликта, источник карточки.
- `coverage` — контракт/год: строки истории и торгов, отсутствие SETTLEPRICE,
  наличие карточки и **текущих наблюдений** стоимости пункта/ГО, границы времени
  наблюдений, число строк истории с архивом ставок риска по активу на ту же дату.
- `asset_year_coverage` — сводка по году и активу из реестра, включая отдельную
  группу неизвестного актива. Наличие наблюдений не означает их применимость в этом году.
- `missing_registry`, `before_start`, `continuous_before_start`, `after_expiration`,
  `nonpositive_settlement`, `gazr_scale_break` — детализация P1.
- `settlement_fallbacks`, `rolls` — все fallback и переходы со способом получения
  коэффициента: `previous_date`, `roll_date`, `missing_pair_ratio_one`.
- `duplicate_registry`, `ambiguous_price_dates`, `edition_overlaps` — контроль
  однозначности связей и пересечений редакций одного семейства/даты проверки.
- `unverified_editions` — количество скачанных и проверенных редакций по активам.

Проверенный отчет содержит **15 496 строк контракт/год**. Дубликатов SECID в
реестре и нескольких досок на SECID/дату не найдено; пересечений редакций
внутри одного источника и одной даты проверки нет. Это не проверка интервалов
параметров контрактов: таких подтвержденных интервалов пока нет.

### API потребителя

```python
from moexutils import futures_audit

coverage = futures_audit.read_coverage(secid='SiZ5_2015', year=2015)
metadata, sections = futures_audit.report()
```

API не загружает данные из сети и не изменяет DuckLake. Недостающие таблицы
приводят к явной ошибке; отсутствующий архив не трактуется как полное покрытие.
`report()` возвращает словарь метаданных и словарь таблиц polars.

Поля `historical_point_value_status`, `historical_ruble_margin_status` и
`contract_specification_intervals_status` сейчас явно равны `unavailable`.
Это состояние реализованных источников, а не утверждение, что данные невозможно
получить вообще. Наблюдение текущего STEPPRICE в 2026 году не повышает полноту
исторической стоимости пункта за 2015 год. Дубли версий risk limits перед
соединением сворачиваются до наличия дата/актив: их значения здесь не выбираются.
Дата публикации и полный торговый календарь FORTS отчетом не восстанавливаются.
