# Документация moexutils

Параметры фьючерсов, наблюдения ГО и архив ставок риска:
[источники, ограничения и API](futures-parameters.md).

Пакет и пайплайн данных Московской биржи (MOEX ISS) и ставок Банка России: акции и индексы (рабочий набор и весь рынок), облигации всего рынка с 1997 года (включая корпоративные, валютные и погашенные выпуски) с купонами, амортизациями и офертами, все фьючерсы FORTS с 2002 года с реестром контрактов и непрерывными рядами, валютный рынок и фиксинги, ключевая ставка ЦБ, RUONIA, кривая бескупонной доходности, параметры бумаг по датам (с 2024); скорректированная цена (adj close), капитализация, проверка качества данных. Обзор проекта — в [README](../README.md).

## Модули пакета `moexutils`

| Модуль | Назначение |
|--------|------------|
| `stocks` | Акции и индексы (рабочий набор) в хранилище: загрузка из ISS, сплиты, переименования, снятые с торгов, сектора, adj_close, капитализация, ключевая и безрисковая ставки; копии реестров `ref_*` и `stocks_adjusted` для SQL |
| `history` | Рынки «все инструменты за дату» (`DATASETS`): облигации, фьючерсы, все акции и фонды, все индексы, валютный рынок, валютные фиксинги; реестры карточек бумаг `bonds_securities`, `shares_securities` |
| `rates` | RUONIA с cbr.ru; кривая бескупонной доходности MOEX (КБД): параметры, доходности по срокам, ОФЗ кривой |
| `refdata` | Параметры бумаг фондового рынка по датам (объем выпуска, листинг, номинал, купон) с 01.04.2024 — только изменения |
| `indices` | Состав и веса индексов по датам (17 основных индексов, IMOEX с 2001 года) |
| `cashflows` | Денежные потоки облигаций из сводной выдачи ISS `bondization`: купоны, амортизации, оферты |
| `contracts` | Реестр фьючерсных контрактов FORTS, перекодировка истории после повторного листинга кодов, непрерывные ряды по основным активам |
| `futures_audit` | [Отчет P1 и покрытия параметров по контрактам, активам и годам](futures-audit.md); чтение без исправления источников |
| `futures_rms` | Архивы staticparams, staticparamskeyterm и rclimits; все сроки и категории риска |
| `specification_editions` | Исследовательский реестр редакций документов, без подтвержденной применимости к контрактам |
| `futures_params` | Наблюдения параметров/ГО, карточки текущих и истекших контрактов, архив ставок риска с 22.05.2018 |
| `options` | Серии и контракты опционов: страйки, Call/Put, экспирации, базовые активы и размер лота |
| `openpositions` | Дневные позиции физических и юридических лиц по фьючерсам и опционам |
| `quality` | Проверка качества данных, история прогонов и замечаний |
| `lake` | Хранилище DuckLake: каталог PostgreSQL `moex_lake`, файлы Parquet в `<MOEX_DATA_ROOT>/lake`; запросы → polars, запись и синхронизация по ключу, снимки (`as_of`), представления, обслуживание |
| `iss` | Доступ к MOEX ISS: HTTP-сессия с таймаутом и повторами, разбор ответов в polars |
| `bondmath` | Доходность к погашению, модифицированные дюрация и выпуклость облигации (упрощенная модель) |
| `backup` | Резервная копия каталога хранилища (`pg_dump`), проверка, ротация |
| `notify` | Уведомления Windows о сбоях и новых замечаниях ночного обновления |

| `update_data.bat` | Запуск на Windows: выбор интерпретатора (`MOEX_PYTHON` → conda `py312` → `python`), проверка, что импортируются `moexutils`, `polars` и `duckdb` |
| `scheduled_update.cmd` | Обертка для задачи планировщика `MOEX data nightly` (вт–сб 00:30), лог в `logs/update.log` |

| `scripts/reader_role.sql` | Роль PostgreSQL `moex_reader` только для чтения хранилища: роль создана этим скриптом; повторно — от `postgres` после новой установки Postgres или восстановления каталога |
| `marimo/bond-market.py` | Ноутбук обзора данных: кривая ОФЗ, G-спреды, RGBITR против IMOEX |

## Установка и запуск

```bash
pip install -e ".[dev]"          # пакет + pytest, ruff; для ноутбука — ".[notebooks]"
python update_data.py            # полный цикл обновления
python update_data.py --check    # только проверка данных
ruff check . && pytest -q        # линтер и тесты
```

Рабочее окружение — conda `H:\conda\envs\py312` (пакет установлен в него в режиме `-e`); системный `python` без `polars`/`duckdb` не подходит. Данные лежат в `MOEX_DATA_ROOT` (`F:\moex-data`), реестры `metadata/` — в проекте. Хранилищу нужен локальный PostgreSQL (служба `postgresql-x64-17`) и пароль роли `moex` в `%APPDATA%\postgresql\pgpass.conf`; без них данные недоступны (обновление пишет предупреждения). Проекты-потребители ставят пакет командой `pip install -e <папка moexutils>` и читают под ролью `moex_reader` ([контракт данных](data-contract.md)).

## Зависимости

- **requests** — ISS MOEX и cbr.ru; **lxml** — HTML-таблицы cbr.ru (ключевая ставка, RUONIA); **openpyxl** — Excel с числом акций
- **polars**, **duckdb** ≥ 1.5 (с расширениями ducklake, postgres) — данные и хранилище
- **pyarrow** — обмен данными DuckDB ↔ polars; **numpy** < 2 — совместимость со сборками пакетов окружения под NumPy 1.x
- extras: `notebooks` — **marimo**, **plotly**; `dev` — **pytest**, **ruff**
