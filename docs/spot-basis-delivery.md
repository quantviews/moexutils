## Чтение в futures-analytics

```python
from pathlib import Path
import polars as pl
from moexutils.reference_metadata import sha256, verify_package
from moexutils.spot_basis_delivery import read_dividends

package = Path('F:/moex-data/reports/futures-analytics-spot-basis-20261015')
assert sha256(package / 'manifest.json') == 'b77a895f18667a51b82822c852aa4c3edfd591ebab6e0119c8ba5adb04c62ba1'
verify_package(package)

# Только сведения, доступные на конкретный исторический вход.
known = read_dividends(package, '2023-03-17T14:36:00+03:00')
limitations = pl.read_parquet(package / 'limitations.parquet')
paired = pl.read_parquet(package / 'minutes/common_minutes.parquet').filter(
    pl.col('same_active_minute')
)
settlements = pl.read_parquet(package / 'metadata/meta_planned_settlements.parquet')
```

read_dividends требует часовой пояс и запрещает дату позднее снимка. Сначала
отбираются verified/proven события с доказательствами публикации/редакции,
затем разрешаются известные supersedes-цепочки. Поздняя поправка не удаляет
событие из более раннего ответа. Корректность сверена с читателем dividends на
конечном снимке; на реальном примере SBER в 14:35:59 события ещё нет, в 14:36:00 есть.
Код чтения входит в moexutils; его копия сохранена как builder.py для аудита.

Нельзя использовать конечный public_as_of.parquet на всех исторических входах.
Отсутствующая строка не означает нулевой дивиденд. Статусы proposed, approved,
paid различны; сумма рекомендации не является подтверждением выплаты.
При неизвестной базе акции нельзя автоматически применять сплиты или выдавать
нормализованную сумму за подтверждённую.

Минутный срез — 18:45 Europe/Moscow, сигнал не раньше 18:46; фактическая задержка
публикации неизвестна. Требуются сделки обеих ног внутри этой минуты, перенос
последней цены из другой минуты не допускается. Даже активная общая минута
не доказывает точную одновременность сделок или исполнимость по ценам свечи.

## Приёмка и оставшиеся ограничения

Политика различает ошибки и пробелы:

- Блокируют: нарушенные хеши/схемы/связи, неверная идентичность, запрет поставщика,
  нерешённый конфликт, нарушенная причинность, отсутствие всех реальных примеров.
- Допускаются с явной маркировкой: неполное покрытие, неизвестная база акции,
  недоказанные исторические факты, неизвестные фактические платежи и отсутствие
  события/примера в отдельном году. Неизвестное сохраняется неизвестным.

Результат проверки dividends: 0 блокирующих ошибок, 51 ограничение, 7 успешных
примеров. У спецификаций остаются три непроверенных текста НКЦ и четыре редакции
без локальных оригиналов; отсутствие всех индивидуальных исключений не доказано.
Метаданные, наблюдавшиеся в октябре 2026 года, не объявлены известными в прошлом.
Плановый календарь расчётов используется по принятой модели, не как факт исполнения.

`history_complete=false`, `execution_ready=false`, `full_backtest_ready=false`.
Приёмка передачи завершена по исходному ТЗ; полноценный расчёт стратегии, требующей
всех выплат и точной исполнимости, этой поставкой не подтверждён. Потребитель обязан
исключать неподдержанные расчёты либо отдельно согласовать явно названные допущения.
Автоматического подключения пакета и перезапуска стратегий не выполнялось.

## Воспроизведение

Сначала запустить приёмку dividends с новым выходным каталогом (см.
[приёмщик](dividends-acceptance.md)), затем:

```powershell
python -m moexutils.spot_basis_delivery `
  --audit F:/moex-data/reports/dividends-acceptance-20261015-policy-v2 `
  --prices F:/moex-data/reports/spot-basis-20261015-v4 `
  --minutes F:/moex-data/reference/spot-basis-minutes-20261015 `
  --metadata F:/moex-data/reference/metadata/363389bd86bb0a48d7a619e89c9faab17a97442e33e2cc370909a76ef6d62f50 `
  --output F:/moex-data/reports/NEW_SPOT_BASIS_DELIVERY
```

Существующий каталог не перезаписывается. Новая сборка получает новый manifest;
потребитель закрепляет конкретный хеш, а не выбирает последнюю папку по времени.
