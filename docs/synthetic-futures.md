# Синтетические фьючерсы: данные, методика и использование

Состояние на **15 октября 2026 года**. Текущий объединённый пакет
[universe24](barchart-universe24.md) содержит **160 контрактов, 185348 строк**
COFFEE/ORANGE/TTF. Покрытие проверено с 01.01.2020 по **05.10.2026**:
155 переходов имеют обе цены в один день; отсутствующих ближних серий на
наблюдаемых сессиях нет. Даты без баров всех соседних серий отмечены отдельно.
Это проверка данных, не новый расчёт доходности или подтверждение исполнимости.

Ранее на отдельном архиве **120 контрактов, 135999 строк** построены ряды
с **02.01.2020 по 31.12.2024** и выполнены 48 бэктестов. Приведённые ниже
результаты этих расчётов не пересчитывались при объединении universe24.
Для ED, UCNY и NIKK собраны референсы первого прототипа; равноценная контрактная
история для них пока не построена.

## Что означает «синтетический фьючерс»

Различаем три уровня:

1. **Исходный зарубежный контракт.** Реальные дневные бары Barchart конкретной
   серии: например, KCH25. Эти цены не моделируются и не подменяют данные MOEX.
2. **Ценовой прокси.** Зарубежная цена переводится в выбранные единицы котировки.
   Получается условная цена для исследования базового рынка, без подгонки базиса.
3. **Непрерывный ряд и бэктест.** Серии выбираются по заранее заданному календарному
   правилу. Индекс для сигналов и прибыль стратегии рассчитываются отдельно.

Фьючерсов MOEX в ранние годы могло не существовать. Поэтому такие ряды не являются
восстановленной историей их сделок, расчётных цен, ликвидности или гарантийного
обеспечения. `synthetic=true` относится к построенному прокси; исходные бары —
наблюдения зарубежного поставщика. `execution_model_ready=false` сохраняется.

## Какие рынки и версии доступны

| Рынок | Исходник | Текущая готовность |
|---|---|---|
| COFFEE | Barchart KC, отдельные Coffee C | Контрактный архив, непрерывный сценарий 2020–2024, бэктест |
| ORANGE | Barchart OJ, отдельные FCOJ | Контрактный архив, непрерывный сценарий 2020–2024, бэктест |
| TTF | Barchart TG, отдельные TTF | Контрактный архив, непрерывный сценарий 2020–2024, бэктест |
| ED | Yahoo EURUSD=X | Спот-референс; не история форвардного курса или фьючерсного carry |
| UCNY | Yahoo CNY=X | Спот CNY за USD; не CNH и не исторический фиксинг MOEX |
| NIKK | Yahoo 1329.T | Рыночная цена ETF; не NAV и не сам Nikkei 225 |

Первый прототип `foreign-quote-proxy-v1` использует шесть Yahoo-референсов, включая
KC=F, OJ=F и TTF=F. Его глубина и ограничения — в [описании источников](foreign-reference.md).
Он не заменяет более поздний архив отдельных серий Barchart.

`foreign-contract-proxy-v2` — отдельное сравнение 33 зарубежных серий 2025–2026 с
MOEX и построение цепочки на наблюдаемом календаре MOEX. Его правило перехода —
не менее семи календарных дней до экспирации. Это другой эксперимент, чем
историческая цепочка 2020–2024 с переходом 15-го числа.

`historical-foreign-chain-v1` — текущая историческая цепочка COFFEE/ORANGE/TTF.
Криптофьючерсы и бессрочные инструменты **не входят в этот синтетический архив**;
их реальные данные MOEX описаны в [пакете всех фьючерсов](all-futures-bundle.md).

### Проверки качества

- Все ожидаемые серии присутствуют; дублей `symbol/date` и NULL close нет.
- Признаков обрезки по запрошенному лимиту и непокрытых диагностических окон нет.
- Внутри диапазона каждой серии нет пропусков относительно наблюдаемых дат соседних
  серий того же рынка. Даты, отсутствующие у всех серий, этим способом не выявляются.
- Последние бары 120 серий совпали с расчётом по текущим правилам и приближённым
  праздничным календарям. Это **расчётная сверка**, не архив официальных дат экспирации.
- Независимое историческое подтверждение найдено для KCH20: 19.03.2020. Для остальных
  дат исторические редакции календаря не подтверждены; `full_history_verified=false`.
- После добавления пограничных серий все 3690 прежних доступных цен цепочки и
  выбранные для них контракты остались неизменными.

Источники календарных правил, официальный якорь и подробности проверки:
[аудит исторического архива](barchart-history-probe.md).

## Файлы и колонки

### Исходный объединённый пакет

`contracts.parquet` — строки отдельных контрактов. Ключ: **symbol, date**.

| Поле | Тип | Смысл |
|---|---|---|
| symbol | String | Символ поставщика, например KCH25; не SECID MOEX |
| asset | String | COFFEE, ORANGE или TTF |
| date | Date | Дата дневного бара, не время его публикации |
| open, high, low, close | Float64 | OHLC в исходных единицах поставщика |
| volume | Float64 | Объём; нули сохранены, число проверяется при импорте |
| open_interest | Float64 | Открытый интерес; отсутствующее значение может быть NULL |
| price_kind | String | `provider_close_not_verified_settlement` |
| execution_model_ready | Boolean | false |

`close` нельзя автоматически переименовывать в официальную settlement price:
браузерный ответ не подтверждает эту семантику для всех дат.

`manifest.json` задаёт серию, рынок, месяц поставки `delivery_month`, диагностические
окна и `calendar_status`. Месяц поставки не является точной датой экспирации.
`summary.json` содержит статус, покрытие, происхождение, хеш кода и хеши артефактов.
В `inputs/1/` и `inputs/2/` сохранены исходные пакеты, включая raw JSON и их summary.

### Построенные ряды

`front_quotes.parquet`: ключ **asset, date**, 3915 строк календарной сетки.

| Поля | Смысл |
|---|---|
| symbol, delivery_month | Выбранная серия и её месяц поставки |
| scheduled_cutoff | 15-е число месяца перед поставкой; с этой даты серия уже не выбирается |
| proxy | CLOSE, переведённый в единицы прокси; NULL при отсутствии цены |
| volume | Объём выбранной серии |
| peer_session | На эту дату есть хотя бы один бар данного рынка |
| coverage_status | Доступность выбранной серии/бара или отсутствие наблюдаемой сессии |
| previous_date, previous_symbol | Предыдущая наблюдаемая сессия и выбранная на ней серия |
| roll_event | Смена серии относительно предыдущей наблюдаемой сессии |
| within_contract_return | Простая доходность только внутри той же серии; на переходе NULL |
| synthetic, execution_model_ready, model_version | true, false, `historical-foreign-chain-v1` |

Значения `coverage_status`: `available`, `missing_boundary_contract`,
`missing_selected_bar`, `no_peer_session_unverified`. В текущем пакете встречаются
только первое и последнее. Неизвестные сессии не объявляются праздниками.

`rolls.parquet` содержит 115 переходов: дату, рынок, старый/новый символы, `proxy`,
исходный `old_close`, переведённый `old_proxy` и `roll_gap_not_pnl = proxy − old_proxy`.
`coverage.parquet` — количества строк по рынку и статусу. `summary.json` — параметры
модели, ограничения, хеш входного summary, кода и результатов.

## Единицы цен и правило перехода

| Рынок | Исходная единица | Множитель | Единица proxy |
|---|---|---:|---|
| COFFEE | US cents/lb | 0.01 | USD/lb |
| ORANGE | US cents/lb | 0.01 | USD/lb |
| TTF | EUR/MWh | 1 | EUR/MWh |

Это перевод **котировки**, а не стоимости целого контракта. Размер лота, стоимость
шага, рублёвый курс и исторические параметры MOEX в множитель не включены.
Базис, carry и поправки к будущим ценам MOEX не оцениваются.

На дату выбирается ближайший месяц поставки, у которого ещё не наступило 15-е число
предыдущего месяца. Например, январская серия перестаёт выбираться 15 декабря.
На выходных смена проявляется на следующей наблюдаемой сессии. Выбор выполняется
до проверки наличия цены: недоступная серия не заменяется более дальней ради
заполнения пропуска. Это заранее заданный ранний переход, не фактическое историческое
правило MOEX или Barchart. Back adjustment и заполнение отсутствующих цен не применяются.

| Рынок | Дат с ценой | Первая дата | Последняя дата | Будних дат без баров всех серий |
|---|---:|---|---|---:|
| COFFEE | 1258 | 02.01.2020 | 31.12.2024 | 47 |
| ORANGE | 1258 | 02.01.2020 | 31.12.2024 | 47 |
| TTF | 1290 | 02.01.2020 | 31.12.2024 | 15 |

## Как читать и воспроизвести

Из проекта moexutils, для проверки всего пакета и календарного аудита:

```powershell
python -m pip install -e ".[reference]"
```

```python
from moexutils.barchart_history_audit import read_package

contracts, manifest = read_package(
    r"F:\moex-data\reference\barchart\history-2020-2024-extended-20261014"
)
# contracts — polars.DataFrame; исходные единицы ещё не преобразованы.
coffee = contracts.filter(contracts["asset"] == "COFFEE")
```

`read_package` проверяет статус и контрольные суммы артефактов, включая манифест.
Более узкий `barchart_pilot.read_contracts` проверяет версию и хеш Parquet, но сам
не отклоняет partial-пакеты: при его использовании статус нужно проверять отдельно.

Из корня futures-analytics:

```powershell
python -m futures_analytics.historical_chain --package F:/moex-data/reference/barchart/history-2020-2024-extended-20261014 --output outputs/NEW_CHAIN
python -m futures_analytics.historical_backtest --package F:/moex-data/reference/barchart/history-2020-2024-extended-20261014 --chain outputs/NEW_CHAIN --output outputs/NEW_BACKTEST
```

Всегда указывать новые выходные каталоги. Читатель бэктеста проверяет хеши обоих
пакетов и соответствие цепочки исходному архиву. Не брать первый подходящий каталог
по маске: старые частичные и предварительные результаты также сохранены.

## Использование в бэктесте

Сигналы рассчитываются по аддитивному индексу, который на переходе сохраняет движение
старого контракта, но исключает разницу уровней между сериями. Нельзя считать
`proxy.pct_change()` через переходы и трактовать результат как торговую доходность.
Нельзя также просто заменить NULL доходности на переходе нулём: так потеряется
прибыль или убыток удержанной старой серии до её закрытия.

В реализованном расчёте сначала переоценивается удержанная позиция по сегодняшнему
CLOSE старой серии, затем закрывается старая и открывается новая. Обе ноги имеют
издержки. Сигнал и размер позиции берутся с задержкой на одну или две сессии.
Пропуск цены удержанного контракта останавливает расчёт. Проверка положительного
объёма текущей и предыдущей сессий может заблокировать ребаланс и оставить старую позицию.

Проверены EWMAC, ансамбль EWMAC, прежний breakout 80 сессий и long-only, всего
48 сценариев: три рынка × четыре стратегии × четыре режима издержек/задержки.
Прогрев — 255 сессий, основное сравнение — 2021–2024. Это P&L на фиксированный
условный капитал с дробными позициями, без рублёвого счёта, ГО и процентов на остаток.

Подробные документы в соседнем проекте:

- [Исторические ряды](../../futures-analytics/docs/historical-chain.md).
- [Бэктест: формулы, параметры, результаты и тесты](../../futures-analytics/docs/historical-backtest.md).
- [Сопоставление v2 с MOEX](../../futures-analytics/docs/synthetic-v2.md).

Ссылки между проектами работают при соседнем размещении обоих репозиториев.
Тренд в этих опытах уступил long-only на кофе и соке; положительный результат TTF
существенно зависит от 2021 года. Это не основание считать торговую стратегию готовой.

## Обновление и оставшиеся ограничения

Получение Barchart выполняется вручную в браузере пользователя. Cookies не сохраняются
в выгрузках и не попадают в Git. JSON импортируется через `barchart_expansion` с
соответствующим манифестом; разные кампании сначала импортируются раздельно.
`barchart_merge` объединяет проверенные пакеты с непересекающимися сериями и сохраняет
происхождение. Повторная версия той же серии требует явной сверки, а не тихой замены.
После добавления данных нужны новый аудит, новый расчёт цепочки и новый бэктест.
Команды импорта и браузерные сниппеты: [исторический архив](barchart-history-probe.md).
Для диапазона 2020–2024 докачка завершена. Пакет universe24 также принят
для снимка по 05.10.2026; ограничения правого буфера и воспроизведение
проверки описаны [отдельно](barchart-universe24.md). Поле `snapshot_end`
не обрезает исходный Parquet: потребитель должен явно ограничивать даты.

Остаются неподтверждёнными исторические времена публикации и версии данных,
официальный календарь всех серий и универсальная семантика CLOSE. Нулевой объём
и плоские OHLC не доказывают возможность исполнения. Не восстановлены исторические
рублёвые ГО, спецификации и ВМ гипотетических MOEX-контрактов. Разные рынки нельзя
суммировать в рублёвый портфель без отдельного валютного и контрактного слоя.
Данные поставщика не следует считать свободными для перепубликации.

Реальная история MOEX, её непрерывные ряды и оценочная ВМ бессрочных контрактов —
отдельные продукты данных; синтетический архив их не перезаписывает.
