# Архив 2020–2024: проверка доступности

Обновление 15.10.2026: этот пакет сохранён как исходная версия и включён
в [universe24 — 160 контрактов](barchart-universe24.md). Проверка объединённой
цепочки выполнена до 05.10.2026. Ниже описан прежний этап, его числа и результаты.

Общий справочник: [синтетические фьючерсы — данные, методика и использование](synthetic-futures.md).

14.10.2026 получены и импортированы все 115 зарубежных контрактов из манифеста
2020–2024, включая 15 пробных. Это архив отдельных серий, не готовая цепочка для бэктеста.
В тот же день добавлены пять пограничных серий 2025 года: итоговый пакет содержит
120 контрактов; исследовательские ряды покрывают период до 31.12.2024 (результат ниже).

Выбраны июльские серии каждого года 2020–2024 по трём рынкам:
`KCN20…KCN24`, `OJN20…OJN24`, `TGN20…TGN24`.
Июль входит в набор месяцев исследуемых типов контрактов. Наличие каждого старого
символа и исторические даты его торговли должны подтвердиться ответами и календарями.
Код символа не считается доказательством даты экспирации.

Проверяемый диапазон каждой серии — с 1 июля предыдущего года по 1 июня года поставки.
Это ориентир глубины истории, не утверждение о дате листинга или торговом календаре.
Пропуски на границах, включая выходные, требуют разбора, а не заполнения.
Старых MOEX-контрактов этим данным не приписываем.

## Запуск в браузере

Копия скрипта: `F:/moex-data/barchart/barchart-history-probe.js`.
[Версия в репозитории](../scripts/barchart_browser_history_probe.js).
На Barchart под своим аккаунтом: F12 → Sources → Snippets, вставить текст, Ctrl+Enter.
Сохранить `barchart-history-probe-*.json` в `F:/moex-data/barchart/`.

Скрипт выполняет 15 последовательных запросов дневных данных отдельных серий с
паузой две секунды, просит до 10000 записей и сохраняет исходные ответы. Cookies
не читаются и не экспортируются. При ошибке останавливается с `stopped.index` и
сохраняет уже полученное. Для продолжения после устранения причины выставить
START_INDEX в этот индекс, новый JSON сохранить отдельно. Не обходить отказ доступа.
Если конкретная старая серия недоступна, это фиксируется как пробел, не заменяется
современной или склеенной серией. Повышенный лимит не гарантирует полный архив.

## Импорт и проверки

```powershell
python -m moexutils.barchart_expansion --source F:/moex-data/barchart/FILE.json --manifest scripts/barchart_history_probe_manifest.json --output F:/moex-data/reference/barchart/NEW_HISTORY_PROBE
```

Несколько JSON продолжения можно указать после --source. Нужен новый выходной каталог.
Проверяются кампания, символы, режим daily, формат, дубли, NULL, возможная обрезка
по лимиту и попадание в запрошенные старые периоды. Даты старого зарубежного рынка
не сравниваются с несуществующей тогда историей MOEX. Импорт сохраняет сырой JSON,
манифест, Parquet, контрольные суммы и отчёт покрытия; неполный пакет маркируется.

Далее, после проверки образца: все месяцы экспираций 2020–2024 — ориентировочно
25 кофе, 30 сока и 60 TTF (115 контрактов, включая 15 пробных). Набор и календарь
подлежат проверке по историческим правилам. Для непрерывного ряда на границах периода
могут потребоваться дополнительные серии конца 2019 и начала 2025 года.
Все 115 серий получены; полнота относительно официального календаря ещё не подтверждена.
Исследовательские непрерывные ряды строятся отдельно в `futures-analytics`;
их покрытие и ограничения описаны ниже.

согласуются с текущими карточками [Coffee C](https://www.ice.com/products/15/Coffee-C)
и [FCOJ](https://www.ice.com/products/30); TTF — месячные серии.


Кампания отличается от пробной: пилот не надо подмешивать в команду полного импорта.

календарь. Все ответы получены 14.10.2026; официальные даты экспираций и
пограничные серии конца 2019/начала 2025 остаются отдельной частью проверки.

## Первый запуск полного набора: остановка по HTTP 429

Файл `F:/moex-data/barchart/barchart-history-2026-10-09T08-42-00-651Z.json`
содержит 82 ответа. На индексе 82 (нумерация с нуля), контракт TGH23, сайт вернул
429. Сниппет корректно остановился; повторные запросы автоматически не отправлялись.
На момент первого запуска оставались 33 ответа; они получены в продолжении 14.10.2026.

Частичный пакет: `F:/moex-data/reference/barchart/history-2020-2024-partial-20261009`,
статус partial_capture. Всего 88089 строк: 20 контрактов кофе / 14945 строк,
24 сока / 17782 строки, 38 TTF / 55362 строки. Дубликатов symbol/date и NULL close
нет; флагов глубины/лимита для полученных ответов нет. Это не проверка полного
биржевого календаря. На пересечении с пилотом 10321 строка, изменений OHLC/объёма/OI
не обнаружено. Контрольные суммы артефактов проверены.

Подготовлена локальная копия `F:/moex-data/barchart/barchart-history-resume.js`:
START_INDEX=82, пауза 10000 мс. Запускать после окончания ограничения сайта;
если ответ в Network содержит Retry-After, соблюдать указанный срок. Не повторять
запросы при продолжающемся 429. Срок блокировки из сохранённого JSON неизвестен:
браузерный экспорт не сохранял заголовки ответа.

Новый JSON продолжения сохранить рядом с первым. Для объединённого импорта
передать оба файла после --source, тот же scripts/barchart_history_manifest.json
и новый --output. Частичный пакет не перезаписывать. Полный архив не объявлять
готовым, пока не получены и не проверены все 115 контрактов.

## Проверка календаря и непрерывные ряды (14.10.2026)

Модуль `moexutils.barchart_history_audit` сохраняет проверку отдельно от исходного пакета:

```powershell
python -m pip install -e ".[reference]"
python -m moexutils.barchart_history_audit --package F:/moex-data/reference/barchart/history-2020-2024-20261014 --output F:/moex-data/reports/NEW_HISTORY_AUDIT
```

Результат: `F:/moex-data/reports/barchart-history-audit-20261014`.
Внутри диапазона каждой серии нет дат, которые присутствуют у соседних серий того
же рынка, но отсутствуют у неё: 0 пропусков. Это не выявляет даты, отсутствующие у
всех серий одновременно, и не подтверждает официальную дату начала торгов.

Последние бары всех 115 серий совпали с расчётными датами окончания торгов.
Расчёт переносит текущие правила назад: кофе — восемь рабочих дней до последнего
рабочего дня месяца поставки; сок — четырнадцать; TTF — два британских рабочих дня
до начала месяца. Источники: [Coffee C](https://www.ice.com/products/15),
[FCOJ-A](https://www.ice.com/products/30/FCOJ-A-Futures),
[ICE Endex TTF](https://www.ice.com/products/27996665/Dutch-TTF-Natural-Gas-Futures).
Календарь — `holidays 0.102`: GB/England для TTF, приближение XNYS для кофе/сока.
NYSE не является календарём IFUS; совпадения не заменяют исторические редакции правил.

Один независимый официальный якорь: KCH20, последний день торгов 19.03.2020,
прямо указан в [уведомлении ICE от 24.03.2020](https://www.ice.com/publicdocs/futures_us/exchange_notices/ICE_Futures_US_DST_Start_2020324.pdf).
Он совпадает с последним баром. У остальных 114 серий даты остаются расчётными,

15-го числа месяца перед поставкой, без подбора по будущей ликвидности и без
заполнения пропусков. Это исследовательский сценарий, не история торгов MOEX.
