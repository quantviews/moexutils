# Архив 2020–2024: проверка доступности

09.10.2026 получены и импортированы все 15 пробных зарубежных контрактов.
Это проверка доступности архива, не готовая цепочка для бэктеста.

Выбраны июльские серии каждого года 2020–2024 по трём рынкам:
`KCN20…KCN24`, `OJN20…OJN24`, `TGN20…TGN24`.
Июль входит в набор месяцев исследуемых типов контрактов. Наличие каждого старого
символа и исторические даты его торговли должны подтвердиться ответами и календарями.
Код символа не считается доказательством даты экспирации.

Проверяемый диапазон каждой серии — с 1 июля предыдущего года по 1 июня года поставки.
Это ориентир глубины истории, не утверждение о дате листинга или торговом календаре.
Пропуски на границах, включая выходные, требуют разбора, а не заполнения.
Старых MOEX-контрактов этим данным не приписываем.

## Запуск в браузере

Копия скрипта: `F:/moex-data/barchart/barchart-history-probe.js`.
[Версия в репозитории](../scripts/barchart_browser_history_probe.js).
На Barchart под своим аккаунтом: F12 → Sources → Snippets, вставить текст, Ctrl+Enter.
Сохранить `barchart-history-probe-*.json` в `F:/moex-data/barchart/`.

Скрипт выполняет 15 последовательных запросов дневных данных отдельных серий с
паузой две секунды, просит до 10000 записей и сохраняет исходные ответы. Cookies
не читаются и не экспортируются. При ошибке останавливается с `stopped.index` и
сохраняет уже полученное. Для продолжения после устранения причины выставить
START_INDEX в этот индекс, новый JSON сохранить отдельно. Не обходить отказ доступа.
Если конкретная старая серия недоступна, это фиксируется как пробел, не заменяется
современной или склеенной серией. Повышенный лимит не гарантирует полный архив.

## Импорт и проверки

```powershell
python -m moexutils.barchart_expansion --source F:/moex-data/barchart/FILE.json --manifest scripts/barchart_history_probe_manifest.json --output F:/moex-data/reference/barchart/NEW_HISTORY_PROBE
```

Несколько JSON продолжения можно указать после --source. Нужен новый выходной каталог.
Проверяются кампания, символы, режим daily, формат, дубли, NULL, возможная обрезка
по лимиту и попадание в запрошенные старые периоды. Даты старого зарубежного рынка
не сравниваются с несуществующей тогда историей MOEX. Импорт сохраняет сырой JSON,
манифест, Parquet, контрольные суммы и отчёт покрытия; неполный пакет маркируется.

Далее, после проверки образца: все месяцы экспираций 2020–2024 — ориентировочно
25 кофе, 30 сока и 60 TTF (115 контрактов, включая 15 пробных). Набор и календарь
подлежат проверке по историческим правилам. Для непрерывного ряда на границах периода
могут потребоваться дополнительные серии конца 2019 и начала 2025 года.
Полный архив и календарь ещё не получены; никакая синтетика старых лет пока не строится.

## Следующая выгрузка: 115 серий

Готов [сниппет полного набора](../scripts/barchart_browser_history.js), копия:
`F:/moex-data/barchart/barchart-history.js`. Запуск такой же через DevTools;
результат `barchart-history-*.json` сохранить в `F:/moex-data/barchart/`.
Между 115 запросами пауза две секунды; обычно потребуется несколько минут.
При ошибке уже полученные ответы сохраняются, индекс продолжения печатается в консоли.

Манифест: [115 серий](../scripts/barchart_history_manifest.json) — 25 кофе, 30 сока,
60 TTF. Июльские серии запрашиваются повторно для независимого полного пакета и
последующей проверки совпадения с пилотом. Месяцы кофе H/K/N/U/Z и сока F/H/K/N/U/X
согласуются с текущими карточками [Coffee C](https://www.ice.com/products/15/Coffee-C)
и [FCOJ](https://www.ice.com/products/30); TTF — месячные серии.
Применимость полного календаря к старым годам и наличие каждого символа требуют проверки.

```powershell
python -m moexutils.barchart_expansion --source F:/moex-data/barchart/FILE.json --manifest scripts/barchart_history_manifest.json --output F:/moex-data/reference/barchart/NEW_HISTORY_PACKAGE
```

Кампания отличается от пробной: пилот не надо подмешивать в команду полного импорта.
Для каждой серии проверяется глубина с начала соответствующего месяца предыдущего
года по начало месяца перед поставкой. Это диагностическое окно, не официальный
календарь. Полная историческая выгрузка ожидается; официальные даты экспираций и
пограничные серии конца 2019/начала 2025 остаются отдельной частью проверки.
