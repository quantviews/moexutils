# Длинная история зарубежных базовых рынков

Текущий общий справочник: [синтетические фьючерсы](synthetic-futures.md).
Ниже описан первый прототип на Yahoo. К 14.10.2026 для COFFEE/ORANGE/TTF отдельно
собраны 120 серий Barchart, построены цепочки 2020–2024 и выполнены бэктесты.
15.10.2026 принят [объединённый пакет universe24](barchart-universe24.md):
160 контрактов с проверкой покрытия до 05.10.2026; прежние бэктесты не пересчитывались.

08.10.2026 пользователь согласовал расширение исследования шести срочных рынков
через синтетическую историю. moexutils получает и хранит исходники, а
`futures-analytics` строит условные котировки и проверяет их. Данные MOEX не заменяются.
Это целевое расширение слоя данных для базовых активов уже существующих фьючерсов.

## Воспроизведение и API

```powershell
python -m moexutils.foreign_reference --end 2026-10-07
```

Опционально `--start YYYY-MM-DD` (по умолчанию 01.01.1970) и `--output NEW_FOLDER`.
Конец по умолчанию — вчера по Москве; незавершенные текущие бары исключаются.
Для запроса используется явный диапазон epoch, а не `range=max`, который у провайдера
может вернуть агрегированные месячные бары несмотря на запрошенный дневной интервал.
Временная зона метаданных используется для даты бара; timestamp не считается временем публикации.

```python
from moexutils.foreign_reference import read_reference

reference = read_reference(
    r'F:\moex-data\reference\foreign\20261008T111426828753Z'
)
```

`read_reference(folder) -> polars.DataFrame` проверяет версию 1, статус complete и
SHA-256 `reference.parquet`. Ключ — `asset, date`; единицы не меняются в загрузчике.
`download(start, end, output)` возвращает каталог. Файлы `<asset>-raw.json`,
`<asset>.parquet`, общий `reference.parquet` и `summary.json` находятся вне git/DuckLake.
Пустая/поврежденная выдача, несовпадающий тикер или валюта, дубли дат и недостаточная
дневная глубина отклоняются. Частичный пакет сохраняет причины ошибок, но не принимается
читателем как готовый; CLI завершится кодом 1.

Загрузка пока **ручная**. Ночной pipeline и фактические ряды MOEX не меняются.
Исходники принадлежат провайдеру: автоматического права их перепубликации пакет не дает.
Yahoo-прототип не содержит отдельные зарубежные экспирации. Для исследования роллов
теперь используется [контрактный архив Barchart](barchart-history-probe.md);
его официальные исторические календари и времена публикации подтверждены не полностью.

## Результат первого прототипа

Модуль `futures_analytics.synthetic_quotes` создает отдельные ряды с `synthetic=true`,
версией `foreign-quote-proxy-v1` и сценарием `zero_basis_no_carry`. Исторический масштаб
не подгоняется к будущим ценам MOEX. Время доступности задается условно через два
календарных дня, с явным признаком неподтвержденной публикации. Это не гарантия
воспроизведения доступного тогда информационного потока.

На поздних 40% пересечения, без оценки параметров на этом участке:

| Актив | Средняя абсолютная относительная ошибка уровня | Корреляция дневных изменений* |
|---|---:|---:|
| TTF | 1,77% | 0,943 |
| COFFEE | 2,71% | 0,846 |
| ORANGE | 4,61% | 0,710 |
| NIKK | 0,95% | 0,540 |
| ED | 0,55% | 0,227 |
| UCNY | 0,30% | −0,046 |

* Сопоставление по одинаковой дате — диагностическое, не торговый сигнал.
Дни смены выбранного контракта MOEX исключены из корреляции; неизвестные роллы
провайдера остаются. Модель выбирает ближайший обычный контракт RFUD не менее чем
за семь календарных дней до экспирации, без оптимизации по будущим результатам.

Малая ошибка уровня у валют **не означает** правильной дневной доходности.
ED и UCNY требуют проверки временной привязки, спот/форвардной разницы и источника;
их нельзя принимать как готовую замену исторической ВМ. NIKK требует дополнительной
проверки NAV, корпоративных событий и несинхронных часов торгов. Остальные три ряда
дают полезное первое приближение, но не проверенный симулятор исполнения.

В `futures-analytics/outputs/synthetic-quotes-v1/` сохранены условные котировки,
построчное пересечение с MOEX, покрытие, метрики раннего/позднего участка, хеши входов
и кода. Рублевая ВМ, издержки, ГО и доходность стратегии в прототип не включены.
Крипта и бессрочные остаются следующим отдельным этапом.

Первым следующим экспериментом стала [выборка отдельных контрактов Barchart](barchart-pilot.md).
Получены 3840 строк шести отдельных контрактов через браузер пользователя.
Предварительное сравнение на одинаковых датах выполнено; результаты и ограничения
приведены в документе эксперимента. Barchart пока не включён в ночной pipeline.
