# Ответ futures-analytics: исторический листинг CNY

Проверка 15.10.2026; история ограничена 14.10.2026. Выполнен приоритет 1.
Исходное ТЗ: [копия запроса](futures-analytics-options-listing-request.md).
Описание файлов и статусов: [контракт пакета](options-listing.md).
Точный путь и SHA-256 manifest: [handoff](options-listing-handoff.json).

## Результат

Для 21 сигнала января 2025 — сентября 2026 найдены 42 серии с подходящими
экспирациями (28–42 календарных дня), но объявленные ISS даты начала всех
этих серий **позже соответствующего сигнала**. Примеры:

| Сигнал | Серия | Начало по ISS |
|---|---|---|
| 03.01.2025 | CNYP060225XE | 22.01.2025 |
| 03.01.2025 | CNYP130225XE | 29.01.2025 |
| 03.02.2025 | CNYP060325XE | 12.02.2025 |
| 03.02.2025 | CNYP130325XE | 26.02.2025 |

Это объясняет отсутствие подходящих сроков в текущих данных. Для конкретных
найденных серий выставлен `not_yet_listed`, а не `never_listed`.
Полнота исторического реестра всех когда-либо назначенных серий не доказана;
переносить будущий листинг назад или автоматически менять правило стратегии нельзя.

Для CNYP051126XE архивный реестр содержит 30 контрактов со страйками 11,9–13,3.
Повторная адресная загрузка ISS на 01.10.2026 дала **26 дневных записей**, все
с NUMTRADES=0, диапазон страйков **11,9–13,1**. BOARDID/NUMTRADES полностью
совпали с локальной историей. Таким образом, диапазон всего реестра 11,9–13,3
не равен набору подтверждённых дневных наблюдений на дату сигнала.

Дальние put ≤11,4961382 и call ≥13,4051447 не найдены в реестре серии;
в текущем торговом списке также нет новых контрактов этой серии за пределами
архивного набора. Их историческое отсутствие **не доказано**: статус `unknown`.
Реальная дата/время появления таких крыльев не установлены.

## Что может использовать потребитель

Пакет подтверждает недостаточность имеющихся данных для заявленных входов.
Его можно принять как диагностический результат первого этапа с ограничениями,
но не как полный point-in-time universe или основание объявить стратегию
исторически исполнимой. `known_at` не восстановлен из даты первого бара.

Для окончательного закрытия неизвестных значений нужен официальный архив
назначения серий/страйков в торги либо ответ MOEX по конкретным датам.
Повторная массовая загрузка сделок этот пробел сама по себе не устраняет.
Приоритеты 2–3 не запускались; решения об изменении DTE или ширины крыльев
относятся к futures-analytics. Никакие исходные пакеты и данные потребителя
не изменялись.
