# План развития проекта MOEX Utils

## Обзор
Проект фокусируется исключительно на данных Московской биржи (MOEX). Основные цели: получение, сохранение и организация данных акций, облигаций и производных инструментов, плюс расчеты метрик и исследовательские ноутбуки (marimo). Никаких ML-моделей или международных данных — это отдельные проекты.

*Обновлено: 30.07.2026 — статус приведен в соответствие с фактическим состоянием.*

## Сделано (июль 2026)

**Акции — ядро (закрыто полностью):**
- Дневные данные из ISS `/history`: закрытие основной сессии, OHLC + WAPRICE, единая методика с индексами; свечи — для интрадей-частот.
- Хранение в Parquet (`data/`), инкрементальное обновление, полное перескачивание (`--rebuild`), атомарная запись.
- Капитализация из метаданных (кэш Excel по mtime), adj_close = дивиденды + сплиты в единой базе.
- Реестры корпоративных событий: `splits.csv` (price/shares/auto + внешний реестр проекта dividends), `renames.csv` (склейка историй с `source_ticker`), `key_rate.csv` (безрисковая ставка), `sectors.csv`.
- Кэш индексов (`indexes/`): IMOEX, MCFTR; обновление шагом 1b `update_data.py`.

**Инфраструктура и метрики (фазы 3-4 — по сути закрыты, раньше срока):**
- `update_data.py` + `update_data.bat`: котировки → индексы → adj_close → market_cap.
- 82 pytest-теста (офлайн, ISS замокан), GitHub Actions CI, логирование через `logging`.
- Метрики: Sharpe по избыточной доходности над ключевой ставкой, MaxDD, беты/альфы/корреляции к индексам, IR/TE, σ-движения, YTM/дюрация облигаций.
- Ноутбуки (marimo, фирменный стиль ВШЭ): обзор рынка (stocks-performance), анализ тикера (ticker-analysis), моментум-стратегия с walk-forward / vol scaling / trend filter / композитным скором (momentum-strategy), портфельный анализ (portfolio-analysis), ARIMA (arima-analysis).

Из фазы 3 намеренно НЕ делаем: Redis, REST API, отдельный веб-дашборд — marimo-ноутбуки закрывают потребность.
